# TRACE-DT

TRACE-DT audits specification and cutoff-tie uncertainty in cancer-target shortlists.
The name is used as a software name; no acronym expansion is asserted.

## R40 code and derived data

**[Download the complete R40 reviewer artifact](https://github.com/heise3/TRACE-DT/releases/download/r40-2026-10-13/TRACE_DT_R40_FULL_CODE_AND_DERIVED_DATA.zip)**

**[Release page and SHA-256 checksum](https://github.com/heise3/TRACE-DT/releases/tag/r40-2026-10-13)**

The ZIP is 525,431,129 bytes and contains:

- The unchanged full R33 code/derived-data base archive.
- R38 unrestricted-membership and list-comparison scientific code and frozen outputs.
- Machine-readable supplementary table resources S1–S45 and current figure-source files.
- R40 corrections to Figure 6 footnote wording and Supplementary Figure S5 rendering; scientific values are unchanged.
- Reproduction instructions and a file-level SHA-256 manifest.

This repository is a release/distribution entry point. The scientific source tree and
derived data are inside the release ZIP, not in the small repository source-code ZIP
automatically generated by GitHub. Download the explicitly named reviewer artifact above.
